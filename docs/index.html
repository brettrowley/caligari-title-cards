    How it works

    Details about how the text is arranged, sized, and distorted.

    Line alignment

    Sets how different lines are arranged relative to each other. "Staggered" is similar to left-aligned, but indents each additional line.

    Note that "staggered" may not work well for text with many lines, or when lines are very short.

    Shrink grammar words
    Reduces the size of words like the, of, und, le and de relative to the surrounding text.
    Line scaling
    Increases the size of shorter lines relative to the longest line of text.
    Max size
    Sets the size (width) the longest line of text can be. This setting is automatically limited to ensure the longest line of text fits the card.
    Angle
    Slants the text up to 20° in either direction. Note that as the angle increases, the lines also begin to bend and twist.
    Jumble
    Applies a random amount of offset and rotation to each character to add chaos to the composition. The "shuffle" button re-randomizes the direction of jumble, but preserves the strength.
    Distortion
    Morphs and exaggerates each character to add variation within the text.

    The inspiration

    The Cabinet of Dr. Caligari (1920) tells its story on title cards. The design of the background and typography in these cards matches the slanted, distorted, and unsettling aesthetic of the film itself.

    I challenged Claude to create a web tool to recreate those title cards.

    A typeface of our own

    No public fonts captured the original type close enough for me, so this project started with Claude crafting our own custom typeface, Holstenwall (cutely named for the setting of the film). Claude analyzed as many title cards as I could find and established rules for the major forms.

    Where the font fell short

    Rendering the font in a webpage was trivial, but I wanted more from this tool. The original title cards were handmade and naturally show variations. The layout of the cards was also skewed and inconsistent, in keeping with the film's surrealism.

    We tried adding multiple variations of each character to the typeface, but this still didn't give us the control I desired.

    Drawing every letter

    Holstenwall got us going, but we had to leave the typeface behind and try something new. This web tool now considers each character as a set of points - based on the original typeface rules - but drawn uniquely for every letter you type. The text is effectively rendered as an image in the HTML canvas.

    By drawing each letter individually, we were able to create settings like "distort", "jumble", and "angle" to fully control the text's surrealist feeling.

    Setting the card

    Using a drawing method also gave us control over the arrangement, placement, and sizing of entire phrases or lines of text. Not as much control as a dedicated graphics editor, but much more than just applying CSS to a text string.

    Painting the card

    Each card is painted in layers, back to front: the background shapes, film grain, the glowing letters, and uneven light like a projector's.
